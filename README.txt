МОЙ ИИ-РЕПЕТИТОР — ПРОТОТИП V1

Это мобильное веб-приложение (PWA), а не APK.

Запуск: загрузите файлы в один каталог на GitHub Pages, Netlify или другой HTTPS-хостинг. Откройте URL на Android/iPhone и добавьте страницу на главный экран.

Уже работает: выбор пяти предметов, диалог, пошаговая помощь для простых арифметических примеров и линейных уравнений, голосовое озвучивание (если поддерживается браузером), голосовой ввод (если поддерживается), сохранение количества занятий и ответов, прикрепление фото для просмотра.

Ограничения: нет подключения к большой языковой модели; свободные объяснения по предметам являются шаблонными. Фото НЕ распознаётся. Нельзя считать эту версию полноценным автономным ИИ-репетитором. Для этого нужен сервер с безопасно хранимым API-ключом, распознаванием изображений, учебной логикой и модерацией.
